# VIDEO-SHORT-001 — «Начни с точки А»

Вертикальный short (Reels / Shorts / TikTok), 1080×1920, 30 fps, 30 с.
Продукт: бесплатная Quick Diagnostic ASHYQ (IELTS / SAT).

## 1. Разбор референса

Референс — 30-секундный горизонтальный (16:9) моушн-ролик SaaS-продукта.

| Время | Бит | Приём |
|---|---|---|
| 0–2 с | Заголовок-фича | Кинетический текст, слово за словом, мягкий blur |
| 2–6 с | UI-демо №1 | Наезд камеры на интерфейс, курсор кликает |
| 6–10 с | Заголовок → график | Линия, всплеск «12.4x», карточка поста |
| 10–17 с | «Сделай своё» / «Оцени до публикации» | Редактор, скоринг 92 |
| 17–19 с | Календарь | Планировщик |
| 19–23 с | Смена цвета | Полноэкранная гарантия на зелёном фоне |
| 23–27 с | Обучение | Карточки треда в перспективе |
| 27–30 с | Энд-карта | Логотип + домен |

**Что берём (ядро и темп):** цикл «короткий заголовок → живой интерфейс»,
новый бит каждые ~4 с, один цветовой «переворот» ближе к концу как
эмоциональный пик, спокойный тёплый фон и один акцентный цвет, энд-карта.

**Что делаем иначе (оригинальное):**

- Формат: вертикаль 9:16 вместо 16:9, крупный текст под мобильный экран.
- Структура: открываем вопросом-хуком к зрителю, а не фичей; ведём по
  реальным трём шагам диагностики; вместо «гарантии» — честное обещание
  (бесплатно, без регистрации, не официальный балл); финал — CTA в профиль.
- Визуал: палитра и шрифты ASHYQ Design v3 (`design/tokens.css`), красный
  ≤15 % кадра; текст выезжает из-под маски снизу (без blur); сторис-прогресс
  сверху; «касания» пальцем вместо курсора мыши; тёмный переворот раскрывается
  кругом из красной точки.
- Сценарий: только подтверждённые факты продукта (см. §3).

## 2. Раскадровка

| # | Время | Экран | Текст на экране |
|---|---|---|---|
| 1 | 0.0–3.2 | Хук: вопрос, затем ответ с красной точкой | «Готовишься к IELTS или SAT?» → «Начни с точки А.» |
| 2 | 3.2–7.4 | Карточка шага 1: тап IELTS, цель 6.0→7.0, срок, «Начать» | «Выбери экзамен и цель» |
| 3 | 7.4–11.8 | Карточка вопроса: выбор ответа, счётчик 3→12, «прогресс сохраняется» | «12 вопросов. ~20 минут.» |
| 4 | 11.8–16.6 | Результат: диапазон 5.5–6.0, цель 7.0, шкалы Reading/Listening | «Увидь свою точку А» + сноска «Пример. Предварительная оценка, не официальный балл» |
| 5 | 16.6–20.6 | Тёмный переворот из красной точки | «Бесплатно. Без регистрации. Честно.» + «Не обещаем балл — показываем, с чего начать.» |
| 6 | 20.6–25.4 | План: чек-лист следующего шага + линия прогресса по замерам + Match Days | «Дальше — план и прогресс» |
| 7 | 25.4–30.0 | Энд-карта: вордмарк, CTA | «Бесплатная диагностика IELTS · SAT» / «Ссылка в профиле @ashyqedu» |

Звук: собственный синтезированный бит 120 BPM (мягкий пульс + пэд),
щелчки на касаниях, «вжух» на сменах сцен. Музыка референса не используется.

## 3. Факты и ограничения (контракт продукта)

- ~20 минут, бесплатно, без регистрации — из `src/components/DiagnosticV3.tsx`.
- IELTS: 12 вопросов Reading и Listening (SAT: 16) — там же.
- Прогресс сохраняется автоматически — там же.
- Результат — **предварительная** оценка, не официальный IELTS/SAT score;
  сноска на экране результата обязательна.
- Числа на экране результата — явно помеченный пример, не данные учеников.
- Никаких гарантий балла, возврата денег, отзывов и «N учеников».

## 4. Сборка

```bash
npm install                       # playwright из devDependencies
cd artifacts/short-video-diagnostic
python3 audio.py                  # soundtrack.wav из таймлайна composition.html (нужен numpy)
node render.mjs                   # 900 кадров через Playwright → ffmpeg (libx264) → MP4
node render.mjs --stills 2.9,15   # PNG-кадры для проверки
```

Результат: `ashyq-short-diagnostic.mp4` (1080×1920, 30 fps, 30 с, H.264 + AAC,
звук нормализован к −1 dBFS) и обложка `cover.jpg` (кадр 2.9 с).
Тайминги сцен, касаний и звуковых акцентов — один JSON-блок `#timeline`
в `composition.html`; `audio.py` читает его же, поэтому звук не разъезжается
с картинкой при правке таймлайна.

`composition.html` можно открыть в браузере: без `?render` он проигрывает
ролик в реальном времени (пробел — пауза, стрелки — перемотка).

# ASHYQ Diagnostic — Design System v2

Источник правды — brand-ассеты кампании (Instagram/Stories/макет лендинга),
лежащие в `/uploads`. Цвета сняты с оригиналов семплированием, логотип
извлечён из постера без перерисовки. Задача системы: сайт должен читаться как
тот же бренд, что человек видел в Instagram, но работать как продукт,
а не как стопка постеров.

## 12 визуальных правил

1. **Палитра только из ассетов.** Cream-бумага `#F7F3EA` (фон мокапа),
   плашечный красный логотипа `#CE1E23`, тёплый чёрный `#211A16` (рваная бумага
   постеров), бумажная карточка `#FCFAF4`, приглушённый тёплый серый для
   вторичного текста. Красный — акцент (хук, CTA, выбор, искра), не фон всего.
2. **Логотип — только оригинал.** Wordmark и icon-плашка — PNG из
   `public/brand/` (извлечены keying'ом красного с постера, без перерисовки,
   без изменения пропорций и звезды внутри «q»). Никогда не набирать «ASHYQ»
   шрифтом вместо логотипа. Тоны: red (светлый фон), cream (тёмный/красный фон).
3. **Три типографические роли + рукописный акцент.** Oswald 600/700 —
   конденсированный гротеск для хуков постеров и UI-дисплея; Playfair Display
   700/800 — серифный голос бренда (hero-хук, brand statements); Inter —
   интерфейсный текст; Caveat — только короткие рукописные пометки и стрелки
   (никогда не вопросы, кнопки, абзацы). Метаданные/таймер — системный mono.
   Все шрифты self-hosted (woff2, cyrillic+latin, `font-display: swap`).
4. **Микро-лейблы как в кампаниях:** mono caps, letterspacing 0.16em,
   с номером секции и красной искрой/квадратом («01 — ЧТО ТЫ УЗНАЕШЬ»).
5. **Воздух прежде всего.** Один сильный заголовок + один главный визуал +
   2–4 детали на экран. Без коллажного спама: в hero ровно одна карточка,
   одно фото и одна рукописная пометка.
6. **Бумажная фактура дозированно:** зерно фона (SVG-шум 3%), рваные края
   только между крупными цветовыми полосами (brand-блок, финальный CTA),
   красный скотч только на коллажных карточках. Читаемость не страдает.
7. **Бренд-элементы точечно:** exam/score-карточки, ticket-мета, чекбоксы
   опций, подчёркивание-штрих под ключевым словом, штампы (`prelim`, `sample`),
   4-лучевая искра из логотипа как буллет — не на каждом экране.
8. **Кнопки-пилюли** как в макете: red pill = главное действие, ink pill =
   следующее, outline/quiet = вторичные. Стрелка → внутри CTA.
9. **Тёмные поверхности = чёрная бумага кампаний:** player card результата и
   marquee-полоса на ink `#211A16` с cream-типографикой и одним красным.
10. **Моушен 150–300ms**, только transform/opacity: fade-up экрана, pop
    диалога, hover-подъём кнопки на 1px. Marquee — медленный transform-цикл,
    отключается при `prefers-reduced-motion`. Никаких частиц, parallax, tilt.
11. **Запрещено:** корпоративный синий, фиолетовые/AI-градиенты, glassmorphism,
    неон, 3D-блобы, стоковые студенты, иконки в стиле Lucide «из коробки»,
    градиентные CTA-карточки, мотивы 🎓, тяжёлые анимационные библиотеки.
12. **Производительность:** hero без тяжёлых ассетов (wordmark ~29 KB,
    фото lazy), шрифты по unicode-range (грузится только cyrillic+latin
    используемых начертаний), below-the-fold секции без JS-тяжести.

## Бренд-ассеты (`public/brand/`)

- `wordmark-red/cream/ink.png` — оригинальный wordmark, извлечён из постера
  IMG_1509 (alpha-keying по «красности»), 1068×336 source.
- `logo-icon.png` / `-192` / `-96` — официальная иконка-плашка (без правок).
- `logo-stamp.png` — штамповая версия иконки (архивная).
- `lesson-grid.jpg` — кроп brand-фото онлайн-урока из постера «Как проходят
  уроки?» (коллаж видеозвонка), для hero/step-визуала.

## Компоненты

`ui/Brand.tsx`: Wordmark, BrandIcon, RedStar (искра), EditorialLabel,
HandNote, Tape, TornEdge, PaperCard. `ui/Primitives.tsx`: Meter, ConfirmDialog.
Экраны: Landing (6 секций), Onboarding (2 шага), quiz/* (спокойный продуктовый
режим), result/* (player card × score report), review/*.

## PNG-карточка результата

`src/lib/card-image.ts` рендерит SVG 1080×1080: чёрная бумага + зерно,
embedded оригинальный wordmark (data-URI) и embedded Oswald woff2
(@font-face внутри SVG), один красный акцент. Fallback без ассетов —
текстовый wordmark, чтобы кнопка «Сохранить карточку» не ломалась.

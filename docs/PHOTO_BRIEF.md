# Фотосъёмка для сайта ASHYQ (PHOTO-SLOTS-001)

Сейчас весь сайт держится на двух снимках (`public/brand/lesson-grid.jpg` 1000×390 и
`public/brand/hero-students.jpg` 900×489): они повторяются в 21 месте, мягкие на больших
экранах, у карточек SAT и «Сезон» обрезан текст постера. Этот бриф — полный список кадров.
Версия для фотографа с рамками пропорций: https://claude.ai/artifact/3qqxFGfUpLXBKLKZx1ZFPF

## Как вставить новое фото

1. Файл кладём в `public/brand/photos/` с именем из таблицы.
2. В `src/data/media.ts` у нужного слота меняем `src`, `width`, `height` (и при
   необходимости `alt`). Компоненты не трогаем — все страницы берут фото оттуда.
3. Обложки статей блога — поле `photo` у статьи в `src/data/blog.ts`.

## ИИ-иллюстрации (PHOTO-AI-001)

Сейчас слоты F-01…F-16 заняты ИИ-иллюстрациями. По Закону РК «Об искусственном интеллекте»
синтетический контент публикуется только с маркировкой, поэтому у каждой:

- видимая пометка «Создано ИИ» — компонент `<AiBadge />` рядом с `<Image>` в слоте;
- машиночитаемая метка в файле — XMP `Iptc4xmpExt:DigitalSourceType = trainedAlgorithmicMedia`;
- alt начинается с «Иллюстрация, создано ИИ:».

Не выдавайте их за реальных учеников, офис или события. Когда в слот встаёт настоящее фото —
уберите `<AiBadge />` у этого слота и «создано ИИ» из alt.

## Общие требования

- JPG, sRGB, качество 80–85 %, 250–600 КБ. Длинная сторона ≥ 2400 px (квадрат — 2000×2000).
- Главное — в центральных 60 % кадра: один файл режется по-разному на компьютере и телефоне.
- Без текста, постеров и логотипов в кадре — при обрезке режутся посреди слова.
- Письменное согласие всех, чьи лица видны; до 18 лет — согласие родителя.
- Естественный свет, тёплый нейтральный баланс, красный — только акцентом.
- Люди в процессе работы, не в камеру (кроме портретов команды и преподавателей).

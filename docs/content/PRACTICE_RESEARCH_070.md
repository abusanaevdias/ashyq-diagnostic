## Три брифа

Общая аудитория: школьники/абитуриенты и родители в Казахстане, преимущественно RU; язык выбран по задаче пользователя, не по неизвестным частотностям. Воронка: problem/solution → практическая проба → обучение при необходимости. Рабочий диапазон550–900 слов на материал; расширение ради числа слов не требуется.

1. **ielts-practice-websites**. Primary: сайты для подготовки к IELTS. Secondary: IELTS тренажёры, Reading с объяснением, официальный образец, практика Writing/Listening. Вопросы: где начинать, чем отличаются ресурсы, как проверить обратную связь. План: прямой ответ → таблица задач → официальные материалы → критерии тренажёра → конкретные ASHYQ-возможности → одна проба. Pillar: /courses/ielts; supporting: self-study-plan, course-choice, mistakes-practice. CTA /trainers.
2. **ielts-mistakes-practice**. Primary: как разбирать ошибки IELTS. Secondary: False/Not Given, overview, Listening correction, повторная попытка. План: прямой ответ → три явно учебных примера → отдельная таблица подтверждённых владельцем кейсов → запись ошибки → следующее упражнение. Pillar: IELTS preparation; supporting: self-study-plan, practice-websites. CTA /trainers. Кейсы — собственная информация бренда, не независимый аудит.
3. **digital-sat-practice-tools**. Primary: сайты для подготовки к Digital SAT. Secondary: Bluebook, Khan Academy, SAT Math, разбор ложных вариантов, модель задачи. План: прямой ответ → распределение задач → официальные источники → модель12+4n → границы упражнений → дальнейшая практика. Pillar: /courses/sat; supporting: sat-math-study-plan, desmos-sat-guide. CTA /trainers.

SEO title, description, H1, coverALT, dates and slug находятся в `src/data/practice-guides-posts.ts`, без дублирующего ручного JSON-LD. Существующий BlogPosting/canonical/sitemap pipeline наследуется; никаких Review/рейтинг/неподтверждённый Person или Course на статьях. Все ссылки в тексте имеют конкретный анкор и нужное место рядом с соответствующей задачей. Диагностика не добавляется как второй конкурирующий CTA.

## Редакторская проверка Sepia и Hormozi

Loaded: Sepia professional-pass, tech-articles, discourse1–3, style-pass, GPT prose priors, voice-skills; Hormozi framework principles. Model: author=GPT version=unknown; executor=GPT version=unknown. Prose layer: prior (не приписываем исполнителю точную релизную таблицу). Venue corpus: существующие ASHYQ self-study/overall/news статьи и публичные формулировки каталога тренажёров.

Проверка по одному критерию: убрать chatbot residue; проверить плотность; задачу каждого абзаца; определённую рекомендацию по условию; реальные источники/числа; заголовки без повторной экспозиции; отсутствие ритуального итога; несимметричную глубину; разную длину предложений; возможность прочитать вслух. Protected: реальные цифры владельца и прямые цитаты не перефразированы в новые достижения. Deferred: внешняя независимая проверка сертификатов/причинного эффекта, недоступные поисковые данные и ещё не измеренные AI-ответы.

Вердикт перед техническим выпуском: подходящая структура для человеческого чтения; точность фактов проверяется отдельно. Sepia не объявляется доказанным средством обхода детекторов или улучшения русскоязычной конверсии. Из Hormozi взяты проблема→механизм→доказательство→один CTA; видео, выдуманная речь владельца, дефицит и гарантии не созданы. Hormozi skill установлен в пользовательский каталог; его видеоскрипты не запускались.

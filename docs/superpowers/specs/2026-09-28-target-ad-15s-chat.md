нам), поэтому клик воспринимается как продолжение ролика.

## 3. Визуал

- Интерфейс чата — **свой**, в токенах ASHYQ Design v3, а не копия WhatsApp
  (без их зелёного, логотипа и иконок): не выдаём себя за чужой продукт.
- Шапка чата: аватар-иконка ASHYQ, «ASHYQ · онлайн».
- Ученик — справа, пузыри `--dark` с текстом `--on-dark`; ASHYQ — слева,
  пузыри `--surface` с тенью. Шрифт сообщений Inter 600, 50–54 px.
- Карточки-сообщения (7.0 и цена) — крупный Manrope 800; красный только на
  зачёркивании и новой цене (≤15 % кадра).
- Безопасные зоны Reels: контент в пределах y 250–1480 px, справа отступ
  ≥150 px под иконки; нижние ~440 px закрыты подписью и кнопкой Meta.
- Энд-карта без нарисованной «кнопки с пальцем»: правила Meta запрещают
  имитацию несуществующих элементов интерфейса. Действие даёт нативная
  кнопка «Отправить сообщение».

## 3a. Стиль по референсу владельца

Референс — вертикальный 42-секундный промо-ролик платёжного сервиса.
Взяты приёмы, но не их графика:

| Приём референса | Как сделано у нас |
|---|---|
| Персонаж-маскот | **«Искра»** — живая четырёхлучевая искра из знака ASHYQ (вариант A, утверждён владельцем 2026-09-28): пропорции знака, большие белые глаза, тонкие чёрные ручки-ножки, в полёте — хвост кометы из логотипа. Код: `artifacts/target-ad-15s-chat/spark/spark.js`. Полутоновый человечек из первой версии снят: слишком близок к маскоту из референса |
| Заголовок: гротеск + рукописный акцент | Manrope 800 + брендовый Caveat в `--red-deep` (цифры — Manrope, у Caveat «0» читается как «С») |
| Своя пастель на каждый бит, телефон по центру | Панели blush → success-soft → bg → dark → bg из токенов v3 выезжают снизу; телефон и переписка непрерывны через три бита |
| Персонаж рядом с телефоном | Мини-искра у телефона реагирует на ответы ASHYQ: стоит → радуется на «7.0» → машет на «вечером» → думает на «сколько стоит?» → «вау» на цене |
| «Речевой пузырь» в хуке | Вопрос ученика в пузыре на первом кадре, затем улетает в телефон первым сообщением |
| Тёмный бит перед финалом | «Ты пишешь — мы подбираем *твою группу*», искра машет (ручки-ножки светлые на тёмном) |
| Персонаж и логотип в финале | Искра влетает с хвостом кометы и приземляется на вордмарк ASHYQ; ниже «Напиши нам в WhatsApp» и стрелка к нативной кнопке Meta |

Искра нарисована кодом из формы знака ASHYQ: не ИИ-генерация и не фото,
маркировка «Создано ИИ» и согласия на съёмку не нужны. Отклонённые раунды
маскота — `artifacts/target-ad-15s-chat/mascot-round-1-rejected/`;
эксперименты с искрой (A/B/C) — `artifacts/target-ad-15s-chat/spark/`.

## 4. Звук

Лёгкий бит, «поп» на каждое входящее сообщение, тихий стук клавиш при
«печатает…», акцент на зачёркивании цены. Без голоса.

## 6. Варианты для A/B

Меняются только первые 1.5 с (хук), остальное одинаково:

- **H1** «а реально поднять IELTS до 7? 😬» — основной.
- **H2** «мне нужен 7.0 для поступления, я успею?» — ответ не обещает
  сроков, только факты потока.
- **H3** «сколько стоит подготовка к IELTS?» — цена раньше: порядок сцен
  цена → поток → формат.
- **SAT** — отдельный ролик только после появления подтверждённых данных по
  SAT: средний 7.0 относится к IELTS, переносить его на SAT нельзя.

## 7. Таргетинг — ограничения

Для аудитории младше 18 лет Meta разрешает таргетинг только по возрасту и
географии (без интересов и пола), поэтому отбирает аудиторию сам креатив.
Предложение: Казахстан (Астана, Алматы, Шымкент + вся страна отдельным
набором), 15–18, русский язык интерфейса; отдельно 18–21 (выпускники и
первокурсники) тем же роликом.

## 8. Честность и открытые вопросы

- Период цены (месяц или курс) не подтверждён, поэтому «цена нового
  потока» без «/мес». **Перед запуском** владелец подтверждает период; при
  «в месяц» добавляем это в карточку.
- «112 учеников, средний 7.0» — данные владельца (`src/data/club-offer.ts`);
  должны подтверждаться скриншотами по запросу.
- Никаких гарантий балла, гранта или поступления.

## 9. Производство

Тот же конвейер, что у VIDEO-SHORT-001: HTML-композиция с `seek(t)` →
Playwright → ffmpeg, звук через `audio.py` (читает тот же `#timeline`).

```bash
cd artifacts/target-ad-15s-chat
python3 audio.py && node render.mjs      # → ashyq-ad-15s-chat.mp4 (15.00 с, 1080×1920)
node render.mjs --stills 3.9             # PNG-кадр для проверки
```

Хуки H2/H3 — правка текста `#bubble` и `#m1`; для H3 — порядок сообщений
в `#timeline`.

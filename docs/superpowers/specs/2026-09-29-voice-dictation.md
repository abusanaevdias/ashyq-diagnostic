# VIDEO-VOICE-006 — «Диктовка IELTS» (ролик с голосом, Remotion + Fish Audio)

Статус: отрендерено 2026-09-29 — `artifacts/remotion-voice/dictation.mp4` (33,9 с, 1080×1920, −14 LUFS), обложка `cover.jpg`.

## Идея

Первый ролик, где звук — сама механика. Зритель слышит короткую запись «как
на Listening» с ловушкой-поправкой, успевает «записать» ответ, потом получает
разбор. Работает как интерактив: досматривают, чтобы проверить себя.

## Сценарий (~34 с, длительность считается по реальному аудио)

| Бит | Голос | Экран |
|---|---|---|
| Хук | RU, диктор ASHYQ: «Проверим твой Listening? Слушай и запиши ответ.» | «Проверим твой *Listening?*», Искра в наушниках, карточка формы уже на экране |
| Запись | EN, «говорящий из теста»: «Okay, so the course fee is fifteen… sorry, I mean fifty pounds, and that includes all the materials.» | Бланк «Course enrolment · Course fee: £ ____», живая волна по реальному аудио, без субтитров (иначе ответ виден) |
| Пауза | — (тиканье) | «5 секунд — запиши ответ», таймер, мигающий курсор в поле |
| Разбор | RU: «Если записал пятнадцать — это ловушка. Говорящий поправился. Правильный ответ — пятьдесят.» | Повтор фразы текстом: fifteen зачёркнуто, fifty подсвечено; в поле «50 ✓» |
| Финал | RU: «Такие ловушки разбираем на занятиях ASHYQ. Проверь свой уровень бесплатно — ссылка в профиле.» | Вордмарк, Искра, «Проверь свой уровень *бесплатно*» |

Пример свой (не из Cambridge). Правило «дослушивай поправки» — то же, что в
эпизоде 3 сериала.

## Техника

- **Remotion** (React): проект `artifacts/remotion-voice/`, анимации через
  `useCurrentFrame` + `interpolate`/`spring`, сцены через `Sequence`/
  `TransitionSeries`, волна — `@remotion/media-utils` (`useWindowedAudioData` +
  `visualizeAudio`, dB-шкала, зеркально от центра), аудио — `<Audio>` из `@remotion/media`, длительность композиции — из длительности аудио
  (`calculateMetadata`). Рендер `npx remotion render` с Chromium из
  `/opt/pw-browsers`.
- **Fish Audio TTS** (`POST https://api.fish.audio/v1/tts`, `format: mp3`):
  каждая реплика — отдельный файл, длительности меряются `ffmpeg -i` → таймлайн
  JSON → Remotion ставит сцены точно под голос.
- **Голоса** (библиотека Fish Audio, подобраны агентом; не голоса реальных
  людей/знаменитостей): диктор RU — «Мужской Профессиональный213»
  `7312c38557eb4fb384e3874e8e9cea67`; говорящий EN — Sarah
  `933563129e564b19a115bedd57b7406a`. Модель `s2.1-pro-free` (на API-балансе 0,
  платные модели отвечают 402). Смена голоса — одна строка в
  `voice.config.json`, затем `npm run tts && npm run render`.
- **Громкость**: каждая реплика нормализуется `loudnorm` до −16 LUFS (голоса
  библиотеки отличаются на ~10 дБ). `--reprocess` — без обращения к API.
- **Синхронизация**: `tts.mjs` пишет в `timeline.json` фразы (silencedetect);
  «fifteen» зачёркивается на первой фразе разбора, «fifty»/«50 ✓» — на
  последней («пятьдесят»).
- **Safe zone Reels**: весь ключевой контент в y = 270–1248; обратный отсчёт
  и расшифровка — внутри карточки (слот волны), не под ней.
- **Ключ API** хранится только в `~/.secrets/fish_audio_key` в контейнере,
  не в репозитории; скрипт читает `FISH_API_KEY` или этот файл.

## Честность

## Как открыть
Пройти /diagnostic → «Сохранить результат в моём профиле» → войти/зарегистрироваться → подтвердить выбранную попытку и аккаунт → сохранить. Затем /me#my-diagnostics. Целевая публичная практика доступна и без регистрации.

Исходная диагностика хранится в аккаунте; её ответам/баллу не приписывается последующее улучшение. Статусы последующей практики пока основаны только на сохранениях этого аккаунта на данном устройстве и явно обозначены так в интерфейсе. Облачный API проверен реальными JWT/HTTP, интерфейс — отдельным синтетическим браузерным прогоном; физический телефон, человеческая речь, качество AI и методическое одобрение не следуют из этих тестов.

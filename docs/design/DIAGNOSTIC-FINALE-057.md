## Experience

“Твоя точка А. И следующий шаг.” The result opens with a native three-scene presentation:

1. Original preliminary range and visible correct/answered counts, with exam scope.
2. One short practical rule selected from actual diagnostic question tags, with wrong/skipped/total evidence and small-sample caveat.
3. One published trainer action, existing answer review and an explicit profile-save entry.

Autoplay advances twice at seven-second intervals and stops on the last scene. Pause is visible at the top from the first frame. Direct scene buttons, arrows, replay and skip-to-review stay available. Manual navigation/focus and opening the share preview stop autoplay. Hidden tabs do not advance. Existing global motion preference, OS reduced motion and the local “Убрать движение” control all remove autoplay and displacement while preserving readable content. No fullscreen trap, audio, invented grade gain or new animation dependency.

The portrait social card is a real 1080×1920 PNG preview, with embedded existing brand assets, original result, one concrete tip and the red route motif “Попробуй → Разбери → Примени”. It contains no name, email, phone, run/account ID, question answers or UTM. Publication remains an explicit user action. The PNG Blob is prepared before file sharing to preserve the mobile user gesture. Unsupported sharing, cancellation, download and clipboard denial have separate outcomes; copyable text remains available. Entire generation has a 15-second timeout, and generation keys prevent use of revoked URLs.

## Conservative display boundary

When fewer than half the diagnostic questions have an answer, the presentation, portrait card, full result card, profile display and WhatsApp export do not present the engine's floor band as a measured range. Instead they show answered/total and say more answers are needed. This is a conservative **display policy**, not a new scoring or statistical confidence model. The underlying engine, score calculation, original frozen snapshot and local run schema are unchanged. A fully skipped run never creates a targeted weakness recommendation.

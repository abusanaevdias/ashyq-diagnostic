# Diagnostic motion — Open trajectory

## Brief
Russian-speaking upper-school IELTS/SAT learners finish a short diagnostic. Need instant understanding of result, observed strengths, one growth focus, published practice. User explicitly rejects generic dark gauge and requests continuous idle motion. Existing Next/React stack and branded tokens retained. GSAP drives the scoped stage clock; no smooth-scroll or WebGL dependency needed for this interaction.

## System
Existing cream bg, ink, red, surface, on-dark, success tokens; no invented colors/fonts. Manrope display + Inter UI. Result is a typographic poster; strengths is an asymmetric evidence index; focus is a concise ruled editorial note; next action is an open path. Phone is composed first, not a desktop miniature. One radius token for player and one pill for utility controls. Reference mechanisms: Lusion real-time continuity (https://www.awwwards.com/sites/lusion), Codrops typographic layer transitions (https://tympanus.net/codrops/2021/09/29/kinetic-typography-page-transition/), GSAP seamless loop docs (https://gsap.com/docs/v3/HelperFunctions/helpers/seamlessLoop/). These are references, not copied assets or awards for this product.

## Motion / trust contract
One GSAP context and ticker, cleanup on scene/unmount. Finite typography entrance, continuing transform-only material motion. Idle never changes score/correctness/skill bars, never implies improvement. Scene autoplay stops on last scene; idle continues. Separate explicit motion pause stops all motion; manual navigation stops scene progression but preserves ambient loop. OS reduced motion, global pause, hidden tab and offscreen stage disable or pause animation. Static remains a complete poster with all text visible. No audio or forced fullscreen. Original scoring/snapshot/provider/RLS/export whitelist unchanged.

## Composition

Focus: topic marker -> typographic rule -> practical sentence -> expandable proof.
Route: diagonal open-path art -> one clear next-action title -> actual trainer CTA and explicit profile anchor.

A dark rounded gauge could be any analytics product. Removed it. The visual now depends on this exact exam's answer states, the true range and ASHYQ red/open-path identity. No ornamental word beneath scope text; no random confetti or fake rolling score.

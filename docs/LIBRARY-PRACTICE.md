# FREE-LIBRARY-QUIZ-026

The native library now offers 322 unique source-coded interactive questions across 47 exercise blocks. The source Speaking review is feedback, not a duplicate question set. A question-at-a-time UI supports radio choices, short input, free writing, stepping backwards/forwards, progress, reset confirmation and copy/manual export. Source instructions and original question text remain available as native disclosures. Source PDFs and migrated content are unchanged.

148 questions have deterministic, source-backed automatic checking: 30 Reading, 60 grammar/collocation, 18 Listening and 40 Writing Lab multiple-choice questions. Choices are extracted only where the source key identifies exactly one option; Listening spelling/time/number variants are explicitly listed from the source. Case, surrounding whitespace, repeated whitespace, curly apostrophes and final sentence punctuation are normalized. No fuzzy matching, semantic grading, estimated band, official exam score or external model call.

174 open questions offer writing and source model/criteria comparison, never automatic correct/incorrect. Speaking Parts 1/2 use the source shared self-review rubric; pronunciation cannot be assessed from a transcript. Part 3 uses the source possible-answer pathways. Full essays use the source possible plans, not a claimed evaluation of the reader's submission. Automatic accuracy counts exclude these questions and unanswered questions. Editing invalidates the old check; returning to a question preserves current-page input.

Answers stay in React memory only. No authentication, network submission, localStorage, student database or new analytics event. Navigation/reload discards answers; the UI explicitly says so. Users can copy all responses or reveal a selectable plain-text export. Client-side keys are intentionally inspectable because this is public self-study, not a secure/official exam.

Checks: `npm run check:practice` combines 322-question extraction/key invariants with browser scenarios for incorrect/correct/edited answers, open-writing score exclusion, step retention, reload clearing, Reading/Grammar/Listening, accepted variants, reset and mobile overflow. It also runs inside the existing CI E2E gate; workflow permissions were not expanded. The shared accessibility/performance gate adds Reading Equipment, Reading Room and Grammar Block 1 to the representative routes. Never report incomplete/superseded runs as passing.

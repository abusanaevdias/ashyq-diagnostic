## Итог объединения

За основу взят Workspace. Сохранены брендовый landing, `/program`, `/progress`,
история прогресса и все визуальные ассеты. Поверх добавлены форма записи,
серверная воронка лидов, защищённая выгрузка и security headers. После слияния
проект обновлён до Next.js 16.3.5, React 19.3 и актуальных dev-зависимостей;
`npm audit` не показывает известных уязвимостей.

Событие просмотра результата одновременно:

1. записывает обезличенный snapshot в локальную историю прогресса;
2. фиксирует обезличенный серверный lead типа `result`;
3. отправляет PII только после явной отправки формы пользователем.

Финальный e2e дополнен проверкой контактной формы и недоступности выгрузки без
`ASHYQ_ADMIN_KEY`.
